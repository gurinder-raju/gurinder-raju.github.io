*At AWS re:Invent 2025, I had the opportunity to speak as an AWS spokesperson about the future of work and some of the emerging patterns I believe agentic AI will create. In the closing section of the talk, I highlighted three patterns in how end users are interacting with applications. The full publicly available session is linked at the end of this post.*

The major shift in applications from native software to web applications fundamentally changed distribution. Applications became instantly accessible through a browser. No installation. Easier updates. Access from almost anywhere. But humans remained the translation layer. We still translate our intent into menus, forms, buttons and clicks so an application can understand what we want. Agentic AI is changing that, and I see three patterns emerging:

**1. In-app agents are the transition step:** The agent sits alongside the application, often as a sidebar. It understands what you're working on, answers questions about the current context and helps you use the application more effectively. But the traditional application is still the primary interface. The agent augments it.

**2. Autonomous agents start replacing the point-and-click translation layer:** As base models become more capable, we increasingly express the outcome we want and let an agent determine how to accomplish it. The agent may operate as our assistant or have an identity of its own as a teammate. Either way, it can navigate applications, use tools and execute workflows on our behalf. The interface starts moving from clicks to intent.

**3. The operating system moves down the stack:** For decades, the operating system (OS) provided a common interaction framework across applications because humans were directly operating them through windows, menus and clicks. As work shifts from continuous editing toward shorter review-and-redirect loops, that role starts to change. The OS remains critical infrastructure, but it becomes less of the experience itself. This shift will increasingly neutralize the historical advantage of popular operating systems built through UI familiarity and workflow stickiness.
